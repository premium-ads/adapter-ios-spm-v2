# PremiumAds Google Mediation Adapter V2 (iOS - SPM)

Swift Package Manager distribution of the PremiumAds Google AdMob/Ad Manager mediation adapter.

## Installation

1. File → Add Packages
2. Enter: `https://github.com/premium-ads/adapter-ios-spm-v2`
3. Set Dependency Rule to "Up to Next Major Version" from `1.0.2`

## Requirements

- iOS 13.0+
- Google Mobile Ads SDK 11.0+ (supports up to v13)
- Xcode 15+

## Usage

See [integration guide](https://docs.premiumads.net/v2.0/docs/google-admob) for full setup instructions.
